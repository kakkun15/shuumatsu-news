# 第七管区 緊急放送網

架空の終末世界のニュースを流し続けるWebページです。iPad・スマホ・PCで開きっぱなしにして、偽の終末世界の雰囲気を楽しむためのものです。終わりはなく、時計に合わせて一日が回り続けます。

**開く → https://kakkun15.github.io/shuumatsu-news/**

> 登場する地名・施設・組織・出来事はすべてフィクションです。実在の警報や放送とは関係ありません。

## 出てくるもの

- **速報**：爆破、線量、黒い雨、通信途絶、正体不明の異常、壁の外の動きなど16分類。「見出し × 状況 × 対応 × 指示」を組み合わせて作るので、1分間隔で24時間流しても、同じ文面はほぼ出ません（見出しの型は約220、ほかに一点もの34本）。見出しは131の話題に分けてあり、本文の1文目（状況）は必ず見出しと同じ話題から選ぶので、見出しと本文が噛み合わないことはありません。出した見出しは端末が覚えていて、開き直しても繰り返しません。
- **続きもの**：調査隊の出発→通信途絶→1名だけ帰還、のように数報にまたがる話が12本あります。
- **親切そうな放送**：発信元不明の「ご案内」がたまに混ざります。数報あとに、本物の局から訂正が出ます。
- **玄関インターホン**：扉の前に、出てはいけない相手や都合の悪い相手が来ます（85種類＋「おかしな点」の組み合わせ）。人とは限りません。犬、置かれた車椅子、床に広がる水、ひとりでに転がる球、天井から伸びるひびなど、人以外が映る回が4割ほどあります（26種類）。
- **壁外監視カメラ**：壁の外の廃墟を映します。人影の列、移動する灯火、昨日はなかった塔、四つ足の群れ、廃止された線路を走る列車、陸の上の船、2つめの月など26種類。時刻で空の色が変わります。
- **管区掲示板**：匿名の住民の書き込み。**実際の時刻で内容が変わります**（朝＝日差しで肌が焼ける・配給の列、昼＝集合住宅の苦情・闇市、夕方＝風向きとにおい、夜と深夜＝寒さ・物音・眠れない人たち）。名前はなく、IDはスレッドが変わるたびに入れ替わります。返信は3割ほどで、残りは独り言です。手足を失った人、親切を装う人、今を商機と見る【広告】、密告する人など、約24通りの「書き癖」と、その場かぎりの書き込みが混ざります。速報・来訪者・壁外の動き・黒板・流れている曲にも反応します。
- **配給所の黒板**：3面が順に切り替わります。①闇市の相場（値段を「日当の何日分か」で表示。日当は据え置きのまま）②本日の配給（何を・何人が並んで・いつ品切れたか。朝6時〜10時が受付）③本日の数字（人口・死亡届・行方不明・出生・来訪・瞬断・爆発）。朝5時に書き直されますが、人口だけは戻りません。速報で断水や略奪が出ると、黒板から品物が消え、掲示板が騒ぎ、広告が便乗します。
- **画面の乗っ取り**：数分に一度、不明な信号が画面全体を奪います（9種類）。何も操作しなくても、数秒〜20秒ほどで自動的に終わります。
- **館内蓄音機**：著作権の切れた56曲（合計およそ143分）を、壊れたレコードのように流します。曲は1曲まるごと入っています。音色（ピアノ／弦／オルガン／オルゴール／声のようなもの）と、盤の状態（針飛び・回転むら・ノイズ・こもり・残響・回転数）を変えられます。自分の音声ファイルを選んで同じ壊れ方で流すこともできます（ファイルは端末の中だけで処理され、どこにも送信されません）。

## 使い方

1. 上のリンクを開く。
2. 初めて開いたときだけ、注意書き（架空であること・警報音の大きさは変えられないこと・明滅があること）が出ます。「受信を始める」で閉じます。
3. **画面をタップ（クリック）すると、下に操作バーが出ます。**「音楽 再生」「次の盤」「警報音」「全画面」「設定」の5つです。数秒で自動的に消えます。
4. 音はブラウザの決まりで、ボタンを押すまで鳴りません。操作バーの「音楽 再生」と「警報音」を自分で入れてください。
5. 「設定」は全画面のシートで、4つのタブ（放送・音／蓄音機／盤の状態／画面・試す）に分かれています。スクロールは要りません。

### iPad・スマホで流すとき

- **スマホ**では、上に速報、下にパネル1枚（インターホン／壁外カメラ／掲示板／観測値／黒板）が出て、約11秒ごとに自動で切り替わります。下のパネルをタップすると次へ進みます。来訪者や壁外の動きがあると、そのパネルに自動で切り替わります。横向きにも対応しています。
- **両端の枠**：iPhoneを横にすると、左右の切り欠き（ダイナミックアイランド）や角の丸みに文字が隠れることがあります。標準で左右に枠を立てて避けています。いらなければ設定の「画面・試す」→「両端の枠」で切れます。
- **ホーム画面に追加**（共有ボタン →「ホーム画面に追加」）して、そのアイコンから開くと、ブラウザの枠なしで全画面になります。iPhone の Safari にはページを全画面にする機能がないため、iPhone ではこの方法だけが全画面になります。
- **音は、ページが見えているあいだだけ鳴ります。** ホーム画面に戻る・別のアプリやタブに切り替える・画面を消すと、すぐに止まります。戻ってくると、止まったところから自動で続きます。自動で戻らなかった場合は、画面のどこかに一度触れると戻ります。

### パソコン・大きな画面で1枚ずつ見る

設定の「画面・試す」→「1枚ずつ表示」を入れると、パソコンでもスマホと同じく、左に速報、右にパネルを1枚ずつ大きく出して約11秒ごとに切り替えます。文字やカメラも画面に合わせて大きくなります。パネルをクリックするか、← → キーで送れます。

## 注意

- **急な明るさの変化と画面の揺れがあります。** 光の刺激が苦手な方は、設定の「画面の揺れ・明滅」と「画面の乗っ取り」を切ってください。端末側で「視差効果を減らす」などを有効にしている場合は自動で止まります。
- 警報音と呼び鈴は大きめで、**ページの中では大きさを変えられません**（設定の「音量」は蓄音機の音楽だけに効きます）。鳴らす前に端末の音量を下げてください。
- 人目につく場所で流すと本物の警報と間違われるおそれがあります。画面下に「この放送はフィクションです」と表示していますが、場所は選んでください。

## ファイル

| ファイル | 中身 |
| --- | --- |
| `index.html` | 画面と動きの本体 |
| `content.js` | 文面の部品（速報・来訪者・乗っ取り・壁外カメラ・掲示板の共通部分） |
| `board.js` | 掲示板の文面（時間帯ごとの書き込み・書き癖・広告・集合住宅の苦情） |
| `music.js` | 曲の音符データ |
| `manifest.webmanifest`、`icon-*.png` | ホーム画面に追加したときの名前とアイコン |

`index.html`・`content.js`・`board.js`・`music.js` の4つを同じ場所に置けば、ダウンロードしてそのまま開いても動きます（文字のフォントだけ Google Fonts から読み込みます）。

## 曲と権利について

- 録音は一切含みません。`music.js` に入っているのは音符の並び（開始時刻・長さ・音の高さ）だけで、音はブラウザの中で合成しています。
- 曲そのものは、すべて作曲者の没後80年以上が過ぎた作品です。
- 曲の著作権が切れていても、楽譜の入力データやMIDIファイルには入力した人の権利が残っていることがあります。そのため、音符データは [Mutopia Project](https://www.mutopiaproject.org/) のうち、入力者が **Public Domain と明記して公開している楽譜**だけから作りました（同じ曲でも Creative Commons 表示のものは使っていません）。Mutopia の説明では、Public Domain の楽譜は印刷・変更・配布・演奏などを制限なく行えます（<https://www.mutopiaproject.org/legal.html>）。
- 例外は2曲です。「主よ、人の望みの喜びよ」（BWV 147）は Mutopia に無かったため、バッハの原曲の音（オブリガート・コラール3声・通奏低音）をこのページ用に5声へ縮約して打ち込みました。音の確認には Nancho Alvarez 氏が公開している校訂譜を参照しています（この譜面ファイル自体は使っておらず、ライセンスの記載もありません）。「パッヘルベルのカノン」は手で打ち込んだ3声版です。
- 楽譜を入力・公開してくださった方々に感謝します。
