# 第七管区 緊急放送網

架空の終末世界のニュースを流し続ける、1枚だけのWebページです。iPadなどで開きっぱなしにして、偽の終末世界の雰囲気を楽しむためのものです。

**開く → https://kakkun15.github.io/shuumatsu-news/**

> 登場する地名・施設・組織・出来事はすべてフィクションです。実在の警報や放送とは関係ありません。

## 出てくるもの

- **速報**：爆破、線量の急上昇、黒い雨、通信途絶、正体不明の異常など。地名や数値は毎回ランダムに組み合わさります。
- **親切そうな放送**：発信元不明の「ご案内」がたまに混ざります。数報あとに、本物の局から訂正が出ます。
- **管区掲示板**：水・配給・線量をめぐる住民どうしの罵り合い。速報や来訪者にも反応します。
- **闇市相場**：物の値段は上がり続け、日当は据え置きのまま。桁が増えすぎると新券に切り替わります。
- **玄関インターホン**：扉の前に、出てはいけない相手や都合の悪い相手が来ます。
- **館内蓄音機**：G線上のアリアとパッヘルベルのカノンを、壊れたレコードのように流します。自分の音声ファイルを選んで同じ壊れ方で流すこともできます（ファイルは端末の中だけで処理され、どこにも送信されません）。

## 使い方

1. 上のリンクを開く（iPadは横向きがおすすめ）。
2. 右上の「設定」から、速報の間隔・警報音・読み上げ・壊れ具合などを変えられます。
3. 音はブラウザの決まりで、ボタンを押すまで鳴りません。「館内蓄音機」の再生と、設定の「警報音・呼び鈴」を自分で入れてください。

## 注意

- **急な明るさの変化と画面の揺れがあります。** 光の刺激が苦手な方は、設定の「画面の揺れ・明滅」を切ってください。端末側で「視差効果を減らす」などを有効にしている場合は自動で止まります。
- 警報音は大きめです。音量に気をつけてください。
- 人目につく場所で流すと本物の警報と間違われるおそれがあります。画面下に「この放送はフィクションです」と表示していますが、場所は選んでください。

## 中身について

- `index.html` 1ファイルだけで動きます。ダウンロードしてそのまま開いても動きます（文字のフォントだけ Google Fonts から読み込みます）。
- 音楽はJ.S.バッハとJ.パッヘルベルの曲（どちらも著作権の切れた作品）を、楽譜の音をブラウザの中で合成して鳴らしています。録音データは含みません。
